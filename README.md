# cc 游戏厅

> 本项目仅供学习研究使用，非商业用途。部分小游戏素材收集整理自公开网络，版权归原作者所有；如涉及侵权请联系删除。

一个面向移动端的网页小游戏合集，收录 15 款经典小游戏，可作为微信小程序 web-view 游戏中心使用，也可直接在浏览器中打开游玩。

▶️ 在线试玩：https://nmww.github.io/moyu-games-cn/

## 特性

- 📱 **移动端适配**：viewport 适配、响应式布局、触摸操控（touch → mouse 兜底），手机浏览器与小程序 web-view 均可流畅游玩
- 📦 **零依赖部署**：JS 库（three.js / Vue / GSAP 等）全部本地化，无需外部 CDN
- 🔌 **小程序就绪**：附带微信小程序壳（游戏列表 + web-view 游戏页），导入开发者工具即可使用
- 🌐 **纯静态托管**：可直接部署到 GitHub Pages / 任意静态服务器

## 目录结构

```
moyu-games-cn/
├── games/              # 15 个游戏（每个目录独立，入口 index.html）
├── libs/               # 本地化的 JS 库与公共样式（mobile.css / touch.js）
├── index.html          # 品牌落地页
└── miniprogram/        # 微信小程序壳（列表页 + web-view 游戏页）
```

## 本地运行

```bash
# 仓库根目录下启动静态服务器
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/games/2048/index.html
```
